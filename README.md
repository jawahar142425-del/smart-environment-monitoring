# Part 1: IoT-Based Real-Time Environmental Sensing and Data Acquisition Unit

## Student

Jawahar S - 25BIT0343

## Project Objective

To collect real-time environmental data using ESP32, MQ135, MQ-2 and DHT22 sensors.

## Hardware Requirements

* ESP32 development board
* MQ135 air-quality sensor
* MQ-2 smoke/gas sensor
* DHT22 temperature and humidity sensor
* Jumper wires
* Breadboard

## Main Functions

* Real-time sensor data acquisition
* Temperature and humidity monitoring
* Air-quality and smoke-related monitoring
* Sensor calibration
* Data validation
* Wi-Fi data transmission

## Expected Output

* Temperature
* Humidity
* MQ135 raw sensor value
* MQ-2 raw sensor value
* Timestamp
* Device ID

## Integration

The collected sensor data will be sent to Part 2 for cloud storage and API processing.
